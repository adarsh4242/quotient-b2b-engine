# Quotient B2B Engine

A full-stack B2B platform designed to streamline business operations, price negotiations, and workflows.

## 🚀 Features
* **Client Frontend:** Interactive UI for users and buyers.
* **Server Backend:** Node.js/Express REST API handling core logic and data processing.
* **Salesforce Integration:** Custom Salesforce ORG integration for B2B pipeline management.

## 🛠️ Tech Stack
* **Frontend:** React / JavaScript
* **Backend:** Node.js, Express
* **Database / CRM:** Salesforce
